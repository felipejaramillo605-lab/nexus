# Nexus

Plataforma de gestión para negocios de servicios que trabajan con citas y personal.

> **Estado:** en desarrollo. Esta página es una presentación; el código del producto es privado.

## El problema

Los negocios de servicios con agenda y equipo (barberías, spas, consultorios y similares) suelen coordinar citas, personal y operación con herramientas separadas o manuales.

## Qué es Nexus

Un ERP/SaaS multi-tenant, pensado como aplicación web instalable (PWA), para que cada negocio gestione su operación en un solo lugar.

## Qué incluye hoy

Funciones que existen en el producto en desarrollo (no implican disponibilidad comercial ni plazos):

- Agenda de citas, con recordatorios por correo y WhatsApp
- Portal público de reservas para clientes
- Clases con cupos y lista de espera
- Membresías
- Inventario y compras a proveedores
- Nómina
- Reportes con exportación a Excel
- Administración de suscripciones por organización

## Para quién

Negocios de servicios con citas y personal, de cualquier tamaño.

## Qué no encontrarás aquí

Todavía no hay demo pública, precios ni lista cerrada de funcionalidades. Prefiero publicar solo lo que está verificado y listo.
